Create live graphics. Run the show.

Lower thirds, scoreboards and title cards for live shows and streams. Start from a template, import your own SVGs, or have your AI coding agent make them. Then play them straight from NoaCG through a browser source, or connect NoaCG Playout to CasparCG with NoaCG Bridge.

Step 1 · Create

Make a graphic the way you already work.

1

From a template

Pick a design from the library, one graphic or a whole kit, and change the text, colours and logo.

Browse templates →

2

With your own SVGs

Draw it in Illustrator or any tool that saves SVG, and import it. Its text becomes fields the operator edits, and you choose how it behaves, such as a scoreboard that counts.

Prepare your file →

You type to Claude Code or Codex: Make me a clean scoreboard for a floorball stream: home, away, period, clock.
3

With your AI coding agent

Use Claude Code or Codex with the NoaCG CLI. The agent builds the graphic, and the CLI checks that it plays and saves it to your library. Ask for a set and you get a production with its rundown. Saving needs a free account.

Install the CLI → Set up your agent →

Also in beta: making a graphic with AI in the browser, and a workspace for rendered video.

Step 2 · Play or export

Then use them however your production works.

NoaCG Playout is the operator's screen: a rundown, preview and program monitors, and Take, Update and Out on the keyboard. Names and scores can change while a graphic is on air.

CasparCG with NoaCG Bridge

NoaCG Bridge is a small Windows program on the playout machine. It connects NoaCG Playout to your CasparCG server and cues the server's clips from the same rundown. This is our main production setup.

OBS and browser sources

Play graphics straight from NoaCG: add the production's output URL as a browser source. In OBS the control panel can sit in a Custom Browser Dock, so you run the show from inside OBS.

Export packages

Download the graphics as HTML templates for your own playout system. Packages for vMix and other systems exist but are not yet tested there.

Open standard

OGraf compatible.

OGraf is the EBU's open standard for web graphics. NoaCG graphics export as OGraf packages for renderers that support the standard.

Free and open source

Everything in the studio is free.

The source is open under the AGPL-3.0. Exported graphics are plain HTML, CSS and JavaScript and keep working without NoaCG. You need an account only for what our service runs for you, such as publishing an output URL or running AI. We would like to hear what you think.
