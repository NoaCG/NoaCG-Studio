Read `.agent-workflows/plan-run.md` (relative to the repo root) now and follow it in full;
it is the canonical procedure, shared with the Claude Code command of the same name. Text after
`$plan-run` names the plan and optionally its date. Read the plan's launch receipt for recorded
owner decisions; a date is a target only with explicit until-complete permission.
The canonical procedure derives operational setup from the authorization and plan, selects
available native coordination through cloud-delegate, and preserves supervisor authority
and fresh independent checkers across session changes. Qualify native continuation before opening
runtime state. Restart grants no new scope or permissions; owner pauses require explicit resume.
