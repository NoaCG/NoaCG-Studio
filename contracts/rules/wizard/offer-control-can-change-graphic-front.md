Offer a control when it can change the graphic in front of the user, and HIDE it, never grey it, when it cannot. Ask the BUILT artifact rather than the category: `cssPaintsWith` for a colour or typeface role, `presetMovesSomething` for a motion card, `STEP_CATEGORIES` for a step reveal, `BRAND_MODES` for a brand. A control whose promise degrades to a no-op for some class of input names that class at the offer site, in the same commit as the control.
