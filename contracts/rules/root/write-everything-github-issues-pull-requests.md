Write everything on GitHub (issues, pull requests, comments, labels) for an outside reader, a developer, user, investor or agent: what happened, what is wrong, what is next and why it matters, about NoaCG only, with every fact a later worker needs. Never put a prompt for a session, conversation, the owner's words or preferences, who asked, or session bookkeeping there; those go in the chat.
