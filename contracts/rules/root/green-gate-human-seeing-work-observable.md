A green gate is not a human seeing it. Work that is observable in the product adds its OWN FILE under `docs/acceptance/owner-queue/` in the same commit: what changed, the ROUTE to it in under a minute, what to look at, and the date. One file per item, never a shared list. An item with no route is not an item.
