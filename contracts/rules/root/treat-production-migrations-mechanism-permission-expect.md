Treat production migrations as a MECHANISM, not a permission, and expect never to run one: a landing applies whatever production is missing once the branch is on `origin/main`. Only a REFUSAL reaches a person, answered per version and filed under `docs/acceptance/owner-queue/` by the branch own session; the landing succeeds either way.
