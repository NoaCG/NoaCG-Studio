Codex review guidelines: a real defect in this product is a broken state rule, wrong playout or export output, data loss or a test-selection gap; report each with its file and line as evidence, never a guess. Raise at most three nits. Skip evidence notes, generated files and style the linters already cover. When nothing needs fixing, say so plainly in the summary.
