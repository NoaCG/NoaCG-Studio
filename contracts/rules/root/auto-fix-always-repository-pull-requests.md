Auto-fix is always on for this repository's pull requests; turn it on without asking. One fixer per pull request: the Claude app's Auto-fix, the Codex chat's scheduled task, or for a wave row its orchestrator. A repair never loosens a test, check or limit; a spec that fails then passes on one commit goes to quarantine.
