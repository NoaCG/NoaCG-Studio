`machine.controls` (`MachineControl[]`) is ADDITIVE OPTIONAL control-surface metadata per operator event - label, section, order, payload field ids, adjust deltas, set figures, add and remove lists, destructive - and it travels INSIDE the template, so an exported control page keeps its labels. One road per field: `add`/`remove` map a lines field to the field whose value is the line.
