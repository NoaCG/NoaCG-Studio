What R1.2a.6 settled:

- **The blanket refusal is gone.** "Another source channel owns this transform or visibility"
  blocked 354 layers in 129 catalog designs (yPercent rows, scale panels, and layers animated under
  a class naming the same element). None refuses that way now; the catalog sweep in
  `e2e/editor-transforms.spec.ts` keys and trims every one of them and moves all but 24 panels
  whose exit ends with Out (a timing refusal).
- **Each control reads the runtime's own tracks and writes them back in their units (D03).**
  `CONTROL_CHANNELS` in `src/blocks/editorAnimation.ts`: Position is x/y plus xPercent/yPercent of
  the layer's border box (the preview reports it as `size`), Scale is scaleX/scaleY or a shared
  `scale`, Opacity is opacity or autoAlpha. A key goes to the channel the layer already animates
  (`writeChannel`); a control that is not animated moves the base by the change
  (`transformOperations` in `animationAuthoring.ts`), so motion the editor does not key stays motion.
- **A layer's owner.** Its motion may live under one other selector naming only that element
  (House Question's `.audience-question` for `#f1`): `layerOwner`/`trackOwners`, read through
  `ownerOf` in `timelineView.ts`. A selector naming several layers, or two naming one, refuses.
- **Time edits work on every channel**; bars of an autoAlpha layer refuse (autoAlpha also sets
  visibility), as does ending an autoAlpha Opacity. A raw transform string refuses keys, never
  time edits. Percent motion is baked into a pixel base only where it is 0.
- `animation.key` now carries a channel for `set` and a control for `remove`/`disable`, with
  `baseValues` (every displayed base value) in place of the single `baseValue`.
