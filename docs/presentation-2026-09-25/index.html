Road 1 · 30 min · You drive

Your own graphic

  1. Draw it to the five rules, or take a sample. /docs#svg-rules samples: lower-third.svg · scorebug.svg · quiz-board.svg
  2. Drop it. The layer names become the field names. noacg.studio/app → New graphic → Import graphic
  3. Type a name longer than you drew for. Watch what the panel does. the Fields step: wider, then a new line, then smaller
  4. Pick what it does. The quiz board locks and reveals; the scorebug counts. the Fields step → What it does
  5. Create, then Finish: add it to a production.
Say it before they ask

If a long name does not grow the way you meant, the answer is one dropdown on the Fields step: When the text is too long.

A typeface Google does not have, or a licensed one, takes the upload road on the last screen before Create.

Road 2 · 25 min · Everyone, then those with an agent

Your coding agent

Everyone, no agent needed
npx -y @noacg/cli scaffold --type scoreboard --design neutral --out ./sb
npx -y @noacg/cli validate ./sb --screenshots ./shots
npx -y @noacg/cli login          once; a browser asks one question
npx -y @noacg/cli save ./sb      prints a link that opens at once
With Claude Code or Codex
  1. Paste the one prompt. It installs, checks itself, and asks what to make. /docs#agent-install
  2. Say what you want. "A clean scoreboard for a floorball stream: home, away, period, clock."
  3. It authors, validates with screenshots, fixes what the validator reports, saves.
