# Review base artwork edits in the editor Alpha

R1.1a adds optional Finish -> Edit this graphic, base Position/Layout offset,
Text/Rectangle/Ellipse tools and base scaling. Existing motion and operator fields stay
in the source document. Direct production remains the primary Finish action.

## Route in under a minute

Run `npm run dev:worktree` on `codex/editor-r1-1a`, open its printed `/app#/new` URL,
choose a template, search for Hairline, skip to Finish, then choose Edit this graphic.
Select Name in the timeline and change Layout offset X to 40. Drag it, Escape, then
undo/redo. Choose Text and click the canvas, or drag to make a text box. Choose Rectangle
or Ellipse and hold Shift while drawing. Use a corner handle or Scale in Properties.

The [walkthrough and evidence](../../research/editor-r1-1a/README.md) include Illustrator
import, save/reopen, exports and desktop/laptop/125% screenshots. This branch is not
claimed deployed; the existing live Alpha link still serves the deployed revision.

## What to look at

Judge whether refining artwork feels predictable, whether coordinates and scale are
understandable, and whether the canvas and Properties have enough room on your laptop.
Base edits should retain existing motion. Creating text should add a field and a layer.
Text-box width should reflow words without changing their font size.

Owner usability acceptance remains open. R1.1b keys and bar editing are not implemented.
