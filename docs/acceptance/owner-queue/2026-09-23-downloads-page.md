# A Downloads page: NoaCG Bridge and the NoaCG CLI, found from the landing page

The two things NoaCG ships that you install now have one public page, `/downloads`, with what
each is for, the Bridge's Windows download and setup steps, and the CLI's install lines for Claude
Code, Codex, any MCP agent and the terminal. The landing page links it from its top bar, from a new
"Two tools you can install" band after the coding-agent section, from the CasparCG line under
"Running a graphic on air", and from its footer. The docs, both READMEs, the studio's profile menu
and Playout settings link it too.

Each card shows the version of the file it links: the newest `bridge-v*` GitHub Release for the
Bridge, npm's `latest` for the CLI. They share one version number but ship separately, so the two
numbers can differ.

## The route, under a minute

1. <https://noacg.studio> - the top bar's **Downloads**, then scroll to the **Downloads** band.
2. <https://noacg.studio/downloads> - both cards; press **Download NoaCG-Bridge.exe** once.

**What to look at.** Whether a stranger reads which tool is theirs from the first paragraph of
each card, and whether the download button gets the 0.4.1 exe. On a phone the Downloads link
leaves the landing's top bar with the other section links; the band and the footer still reach
it. Branch `claude/intelligent-gates-rlo5fp`.
