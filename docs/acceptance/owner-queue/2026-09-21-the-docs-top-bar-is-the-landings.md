# The docs page has the landing's top bar

You said on 2026-09-21 that the docs looked different from the landing page and that the "Open
the studio" button was hard to read. The button label really was grey on amber: the docs header's
link colour outranked the button's own. The docs top bar is now the landing's. It has the same
links (How it works, Going live, OGraf, Docs, Contact), the same "Start creating" button and the
same width. Measured at 1280, 820 and 390 pixels wide, every item in the two headers sits at the
same position and size.

## The route, under a minute

1. Open `https://noacg.studio/` and note the top bar.
2. Click Docs. The logo, the links and the button stay exactly where they were. Only "Docs" turns
   white, to mark the page you are on.
3. Narrow the window below about 720 pixels. On both pages the section links drop out and only
   Docs and the button stay.

## What to look at

- **The button label.** Near-black on amber, the same as on the landing.
- **The section links.** On the docs page, How it works, Going live and OGraf take you back to
  those sections of the landing. The GitHub "Source" link that the docs header used to carry is
  gone, because the landing's header has none.
