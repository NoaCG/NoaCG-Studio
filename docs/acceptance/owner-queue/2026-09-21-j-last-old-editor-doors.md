# The last three doors to the old editor are closed

You said on 2026-09-21 that nothing should link to the old editor now that the new one exists.
The wizard and the control page were done earlier the same night. Three doors were left, and
all three were reachable with Advanced mode off. None of them opens the old editor any more.

- **The new editor's "Existing editor" button** is gone in the default studio. Home, at the
  left of the same header, is the way out. With Advanced mode on, the button is still there.
- **The video workspace's "◫ Graphics" button** now lands on Home's Graphics list. Every
  graphic there opens onto its own page. With Advanced mode on, it still returns to the code
  editor.
- **Apply on a saved brand (Home, Brands)** retints the graphic you have open. It used to
  drop you in the old editor to see the result. It now opens the new editor on that graphic,
  where you can see the new colours and save.

## The route, under a minute

1. Open `https://noacg.studio/app#/home/looks` with Advanced mode off (Settings).
2. Make a brand if the list is empty (New brand, pick a colour, Save), then press Apply on it.
   The new editor opens, with "Editor Alpha" in its header.
3. Look at that header: Home, New graphic, Save, and no "Existing editor".
4. Open `https://noacg.studio/app#/video` and press "◫ Graphics" at the top right. You land
   on Home with Graphics selected.

## What to look at

- **Apply with nothing open.** If you have not opened a graphic this session, Apply retints
  whatever the studio last held, which may be a blank starter. That was true before this change
  too; the difference is that you now see it in the new editor instead of the code editor.
- **The Graphics button beside Home in the video workspace.** In the default studio both now
  go to Home. Say if you would rather the Graphics button went away there.
