# Release @noacg/cli 0.3.4 before the lecture

**One tag push.** A published npm version can never be taken back, so the repository reserves this
step for you (`.github/workflows/release-cli.yml`).

## Why it is worth doing before Friday

0.3.3 shows an agent old screenshots under a green result. `noacg validate <dir> --screenshots
./shots`, run from inside the package as the scaffold's own hint suggests, read the last run's
frames back in as the graphic's assets and then wrote them over the new ones. An edit appeared to
change nothing, `thumbnail.png` stayed the frame of the first validate, and the control page grew
from 41 KB to 987 KB. A cold-start trial with a fresh agent lost two of its eight validate runs to
it; a student would conclude their edits do nothing. 0.3.4 fixes it, and the stress frame no longer
cuts text mid-word (that half is already live, it ships with the site).

## The route, under a minute

After this change is on `main`:

    git -C C:/claude/NoaCG-Studio pull --ff-only
    git -C C:/claude/NoaCG-Studio tag cli-v0.3.4
    git -C C:/claude/NoaCG-Studio push origin cli-v0.3.4

## What to look at

The "Release CLI to npm" run on GitHub goes green, and `npm view @noacg/cli version` answers
0.3.4. Students who already installed the plugin update it with
`claude plugin marketplace update noacg-studio && claude plugin update noacg@noacg-studio`.
