# Source review and deliberate differences

Seventeen source files were freshly fetched by immutable revision through GitHub's contents API. Every SHA-256 matches the prior pinned reference inventory; all ten Studio blobs also match official v0.17 source. The new fetch records include blob IDs in [reference.json](reference.json). Runtime results are recorded separately in the check receipt.

Studio `3142fc7d02934494931eb14e7dc255393e4110d0`, released source `a1e9776120fa19d9f3f9d40ab4b10ae1be034347`: Menubar New confirms before calling `newProject`, then resets history and selection. Open awaits file input, loads source and resets history without its own unsaved-work decision. `fileIO` snapshots and certifies before writing or downloading native source. `projectStore` clears clipboard and resets the timeline before New/load; Stage reads the composition and LayerNode renders its current layers. `useAutosave` saves a separate working snapshot after 500 ms. `historyStore.resetHistory` clears past/future/pending history after replacement. Inspected fileIO, projectStore and projectTimelineSync tests, including New/load playback and clipboard reset. Upstream unit suites were not run.

Eyevinn `616841bd949e3a21137579451123f66c292543f0`: main's template create/switch/delete handlers update TemplateManager and refresh the editor/property/preview views. Creation saves immediately. VisualEditor property updates mutate the model, render and save to localStorage; its drag/resize completion saves too. TemplateManager persists the template map/current ID. Explicit Delete confirms then saves the removal; write failure sets `lastStorageError` and dispatches `ograf-storage-error`. Read the model round-trip, quota-failure and OGraf lifecycle tests. Upstream unit suites were not run.

NoaCG deliberately has a separate named library and disposable draft. Its pre-navigation Save/Discard/Cancel therefore has no direct equivalent in Eyevinn's automatic saves or Studio's direct Open. That distinction lets users abandon an experiment without deleting or replacing a saved graphic. The repaired NoaCG discard must additionally confirm its working-slot write before changing the active session. Comparison is bounded to this lifecycle; no whole-editor parity or upstream source reuse is claimed.

NoaCG review traced `discardCurrentGraphic`, durable receipt capture/claim, the 800 ms autosave drain, `ConfirmSwitchDialog`'s busy guard/continuation, and active command/session lifetime. The independent extension holds real IndexedDB completion delivery, records autosave/replacement order, and adds a newer command edit while discard is pending. Normal user routes remain covered by the unchanged imported-graphic drivers.
