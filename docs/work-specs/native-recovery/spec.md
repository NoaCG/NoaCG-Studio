## Behaviour and boundaries

Keep waves, phases, the GitHub queue and existing repair owners. Use the qualified Claude
launch/recovery paths and Codex one-shot receipts. Do not retry the known Codex CLI auth/catalog
failure or repeat benchmarks. Native inspection must bind session/environment/revision and the
effective permission policy. Unknown sends remain parked until exact native reconciliation.
Only a delivered wake can justify its next one-shot, always inside the original window.

This phase adds reusable receipt guards and a usage-only measurement reader. These do not send
provider requests, install a scheduler, implement permissions, grant ownership or fence remote
actions. The local supervisor remains opt-in. Real probes use only the existing native hosted
automation surface, target this same coding thread and own no production PR recovery.

### AC-1: Identity and permission guard

Node tests reject wrong native identity, revision, stale observations and policy changes.
An idle session with an unknown or pending turn cannot authorize dispatch. Explicit permission
waits remain waits. Native policy read-back and approval continuation remain independently open.

### AC-2: Uncertain delivery guard

Node tests show an exact action/request/native-ID receipt resolves acceptance; timeout, an
empty catalog, an unconfirmed follow-up or an ambiguous match do not authorize resubmission.
Provider-level uncertain delivery is credited only after a real native receipt, never a fixture.

### AC-3: Bounded native re-arm

Observe a real hosted wake into the original coding thread and a re-arm of that same one-shot.
Record the second actual delivery and stop the task. Preserve the original absolute end,
session, worktree and permissions. The disposable probe ends at 2026-10-17T11:15:00Z; at most
two delivered wakes, no third re-arm. A missing re-arm is unknown and visible in the guard's
verdict; an independent outage alarm is not claimed.

### AC-4: Real recovery context

Record native session/receipt, recovery prompt bytes, retrieved bytes where observed and actual
provider input/cache/output counters where exposed. Unknown measurements stay null. Node tests
cover cross-file request deduplication, cumulative baselines/resets and missing counters.
Packet bytes do not establish total model input, billing or context savings. #805 stays open
without real native usage counters and repeated-planning observations.
