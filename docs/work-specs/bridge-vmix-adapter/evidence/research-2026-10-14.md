# Research, 2026-10-14: clips as vMix inputs

The planning session for the re-scoped spec. vMix 29.0.0.49 (Trial) on the development laptop,
driven only over the TCP API on 127.0.0.1:8099 by a small probe client (one command at a time,
`SUBSCRIBE ACTS` on, every state read from `XML`). Media made with ffmpeg in the session's scratch
folder: `clipA_red.mp4` (4 s, 1280x720, red, a 440 Hz tone), `clip B blue.mp4` (3 s, blue, a
space in the name), `still_green.png`, `sting.wav` (3 s). Pictures are vMix's own
`SnapshotInput` of the list input (1920x1080), read as the mean colour of the frame.

## What was measured

| # | Done | vMix answered |
|---|---|---|
| 1 | `AddInput Value=VideoList\|` (no file) | `FUNCTION OK`; a `VideoList` input, `state="Completed"`, `duration="0"`, `selectedIndex="1"`, an empty `<list />`. It took input 1, replacing a Blank of the blank session |
| 2 | `SetInputName` on it, then four `ListAdd` | the XML `title` becomes `NoaCG Clips - clipA_red.mp4` (the name, then the selected file); `shortTitle` stays `NoaCG Clips`. Items are listed as `<list><item selected="true">C:\…\clipA_red.mp4</item>…` with full paths |
| 3 | `ListAdd` with a path that does not exist | `FUNCTION ER File Not Found: <path>`: vMix does refuse some functions, so `OK` is not universal |
| 4 | `ListAdd` of a `.png` and a `.wav` | both accepted and listed; the png plays as a still (green frame); the wav plays with `duration="3000"`, and its frame is black |
| 5 | `SelectIndex 1`, `Play`, list defaults | `Running`; `position` in milliseconds (480, 980, …, `duration="4000"`); at the end it went on to item 2 by itself (Auto Next is on by default), then to the still, which stayed `Running` with `position="0" duration="0"` for 5 s and more. Each switch: `ACTS OK InputPlaying 1 0` and `… 1 1` in the same millisecond |
| 6 | `AutoPlayNextOff`, select 1, `Play`, to the end | `state="Completed"`, `position="4000"` of 4000, `selectedIndex` still 1, and the picture holds the last frame (red) |
| 7 | `LoopOn` (Auto Next off), select 2, `Play` | the selected item loops: position 2480, then 0, 500, 1000 … `loop="True"` |
| 8 | `SelectIndex 1` while item 2 runs | read at once the XML still said item 2; 0.3 s later item 1, `Running` from 260 ms: the switch lands after the `OK`, and the new item plays at once |
| 9 | `Pause`, `Play` | `Paused` at 200 ms, then `Running` from there |
| 10 | `ListRemoveAll` while running | `state="Completed" position="0" duration="0" selectedIndex="0"`, no items; the picture is black (2,0,2) |
| 11 | vMix's defaults, the list in Preview, paused | `Cut` to it: it started (`Running`); `CutDirect` away: `Paused`; `CutDirect` back: `Running` from where it was, not restarted |
| 12 | `AutoPlayOff`, `AutoPauseOff`, `AutoRestartOff` on the list, then the same cuts | nothing changed playback: paused stayed paused on Program, and a running clip kept running off it |
| 13 | `Play` while the list is on neither Program nor Preview | it plays (`Running`, position advancing) |
| 14 | `QuickPlay` | Program changed to the list and it played |
| 15 | A second list `NoaCG Audio` with the wav, defaults | `muted="True"` while not on Program: vMix's audio follows the picture (`InputAudio` ACTS lines follow `Input`) |
| 16 | `AudioAutoOff`, `AudioOn` on it | `muted="False"` and the master meter moved while the list was off Program; ACTS `InputAudioAuto 2 0`, `InputAudio 2 1` |

## What it settles for the plan

- A Video List is a stable vMix input whose file NoaCG can change: the clips player. Take is
  `SelectIndex` of an item and `Play`; Out is `ListRemoveAll`, which leaves black.
- Hold, Loop and the next file are vMix's own: `Completed` on the last frame (rows 6, 7, 5).
- With Auto Play, Pause and Restart off, the player plays what NoaCG took whichever way the vMix
  operator cuts (row 12), the way a CasparCG channel plays whatever the vision mixer shows.
- An audio-only player needs `AudioAutoOff` and `AudioOn` (rows 15 and 16).
- A read right after `SelectIndex` can still show the old item (row 8), so a read-back waits.
- `ListAdd` refuses a missing file with `ER` (row 3), which names the file to the operator.

## Not measured

The Video List's own Loop with Auto Next on (the whole list), a list item's Mark In and Out, the
volume curve of `SetVolume`, the first-frame delay of a large file, UNC paths, the operator's own
preset saved with the players and opened again, and any edition but the Trial.

## How vMix was left

`%APPDATA%\last.vmix` and vMix's `user.config` were copied before the start and put back after a
forced close (SHA-256 `4af6e979…` and `9396e6e6…`, as before; `last.vmix` keeps its 2026-10-01
time). The background service was untouched; vMix's NDI helper exited with it. The media and the
probe client stayed in the session's scratch folder.
