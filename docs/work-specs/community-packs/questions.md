# Community packs: questions for the owner (answered 2026-10-08)

Behaviour choices for [`spec.md`](spec.md), most important first, with the recommendation each was
asked with and the owner's answer. The spec records the answers under "Owner answers, 2026-10-08".

1. **Where does a maker submit a pack?** Recommended: Submit a pack and Your packs on the
   Community packs shelf in the wizard. **Agreed.** Added: research how users build graphic packs
   from Home (select a folder or graphics there and add it as a pack); packs are never exported
   from Playout. Added: CLI and plugin users may add a pack as they import it, only when they ask.
2. **What can be submitted?** Recommended: a whole production with a cue per graphic. **Changed:**
   a pack is a set of the maker's own graphics (a Home folder, a production's graphics, later the
   CLI); no rundown or cues required; Install creates a new production and may add a starter cue
   per graphic; team graphics and anything installed from the shelf are excluded.
3. **Where does the NoaCG admin review?** Recommended: on the same shelf. **Agreed.**
4. **What happens to installed copies when a maker updates?** Recommended: nothing. **Agreed.**
5. **Who sees approved packs?** Recommended: everyone, signed in or not. **Agreed.**
6. **Can a maker withdraw at once?** Recommended: yes, installs stay. **Agreed.**
7. **How does a maker hear the decision?** Recommended: the status in Your packs, no email.
   **Agreed.**
8. **Whose name is on the card?** Recommended: the account's display name. **Changed:** free text
   the maker picks per pack, never requiring their real name or email; a pre-fill is allowed only
   if it is neither. Filed `docs/backlog/choose-your-own-username.md`.
