# Current state and the minimum gap

Research baseline: `origin/main` **eccb018d45527d48bab2cbfe4584e893309f53a0**, inspected 18 October 2026. PR #1390 merge `25384c35d66f22062cf90f81461ddd46ff5b6261` is an ancestor. The isolated research branch was rebased before this audit. No product code or existing work-spec authority was changed.

**Finding:** NoaCG already has a generic scalar binding and control contract. Custom graphics need better source mapping, asset resolution and compatible authoring; they do not need another binding engine. This is a source audit plus a bounded local experiment, not evidence that every proposed UI exists.

## Actual experiment

[election/evidence/report.json](election/evidence/report.json) records 14 passing local checks. Four synthetic templates passed the actual publication gate, parsed with the actual SPX parser, and rendered by actual composeDocument/shared field writer. A loopback stand-in uses actual applyPatch/resolveBindings/diffResolved. It does **not** run production API handlers, hosted storage, OAuth, real Sheets, real results feeds or a broadcast engine. See the report's explicit unproven list.

The old static screen “Add hosted graphic” in `2026-10-custom-graphics-mockups` is superseded: it implied a general provider URL route that this research does not recommend. The nine general Sheet screens in `2026-10-data-sources` remain the baseline; this package adds custom-graphic deltas only.
