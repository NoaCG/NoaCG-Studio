# Options and primary benchmarks

| Option | Covers | Cost / limitation | Recommendation |
|---|---|---|---|
| A — Keep ProductionBindings, improve mapping/adapters | Election party/candidate/bug/ticker, custom scalar overlays, fixed 15-match slots with authored graphic; Fill snapshots; keyed source dictionaries; approved asset names | Does not automatically create a multi-column renderer or bracket behavior from arbitrary artwork. Requires a source adapter for each external provider contract. | **Start here.** Local experiment demonstrates the binding core needs no replacement. |
| B — A plus targeted BehaviourRecipe extension | Visual authoring of repeaters/table slots/brackets without custom JS | Must cover per-row roles, type/asset validation, missing slots and stable reimport; measure existing perRow machinery before adding members | **Conditional follow-on.** Qualify with one bracket and one multi-column overlay. Keep actions in NOACG_ANIM. |
| C — Separate relational engine | Could perform joins/dependencies inside the app | Adds another authority, query language, persistence and recovery model; no scenario here requires it | **Reject for this scope.** Materialize source data upstream and bind existing scalar paths. |

## Primary documentation, checked 18 October 2026

- [SPX HTML templates and definition](https://docs.spxgraphics.com/Documentation/Graphic%2BTemplates/Formats/HTML): DataFields declare fields independently of catalogue families. Reuse declaration-driven controls; don't assume arbitrary SPX metadata already round-trips through NoaCG's narrower parser.
- [EBU OGraf v1 graphics specification](https://ograf.ebu.io/v1/specification/docs/Specification.html): manifest dataSchema and GDD describe data; customActions are a distinct action contract. Keep schema-derived forms and actions separate. Our current adapter notes unsupported structured properties; a standard's capability is not proof of NoaCG UI support.
- [CasparCG AMCP protocol](https://github.com/CasparCG/help/wiki/AMCP-Protocol): graphics UPDATE, PLAY, STOP and INVOKE are separate commands; media playout is separate again. This supports preserving the data/action boundary. Actual Bridge/CasparCG behavior still needs device verification.
- [vMix source-to-title mapping](https://www.vmix.com/help29/DataSourcesTitleMapping.html): the operator selects source/table/column/row and sees a value preview. vMix can fall back to positional column matching; NoaCG should require explicit confirmation for custom fields. This page establishes row selection, **not** stable-key lookup semantics.
- [vMix source control](https://www.vmix.com/help29/DataSourcesControl.html) and [shortcut reference](https://www.vmix.com/help29/ShortcutFunctionReference.html): shared selection updates associated titles; auto-next and row shortcuts control selection. The reference lists pause/play source controls, but this review does not establish that vMix Pause exactly matches NoaCG's proposed source-write freeze. Do not copy that behavior by name alone.
- [vMix images](https://www.vmix.com/help29/DataSourcesImages.html): image source cells can contain paths/URLs. Useful mapping pattern; NoaCG must additionally respect its own publication and package-scope constraints.
- [Google Sheets values.get](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/get): reads a selected range, supports row/column majorDimension and render options. Rows have positions, not durable domain identities. A stable key column and adapter index are our application responsibility. [ValueRange](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values#ValueRange) and schema handling must distinguish omitted trailing cells from explicit semantic clears.

No new Google OAuth flow or general JSON URL reader is silently included: PR1390's Sheet plan uses its agreed shared-link route; DS6 excludes arbitrary JSON-address ingestion in this run. An external connector pushing the existing API is a different route.

See [the election source investigation](election/source-investigation.md) for Yle/Ministry/Statistics Finland evidence. Archived results are useful rehearsal input, but do not prove a live 2027 feed's delivery contract.
