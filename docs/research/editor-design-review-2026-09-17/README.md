# Evidence bundle

Start with `baseline-supplement.md`, then `verification-summary.json`. The raw JSON and PNG
files are observations of the recorded revisions, not acceptance of the future editor.
`artifact-sha256.json` freezes file bytes, including scripts and inputs.

The observation scripts preserve the exact machine-local project/research paths used in this
run. Do not run them blindly in a different checkout or against a real production. Use a
new output directory and update those explicit paths for a repeat. They launch isolated
Chromium profiles and offline Vite servers on 5291/5292, with preview debounce 350 ms.
Queue every browser run through `npm run queue`; do not run multiple copies on those ports.
The scripted fixture seed is assistance and does not count as default product discoverability.

`source-contract-probe.mjs` is a non-browser probe of trusted repository modules and bundled
GSAP. The mockup inspection expects the conversation's rendered standalone preview; the PNGs
and inspection result here are the durable design evidence. The interactive mockup remains
attached to the originating task, not implemented in the product.

Studio fixture JSON is derived from its pinned AGPL-3.0-only demo factory, with 30 rectangular
layers and new property tracks. Preserve that provenance and the repository AGPL licence.
It is reference evidence, not approved output/runtime code for the separately licensed CLI.

Pilot files and raw per-task errors are retained intentionally. A successful process exit
does not erase errors caught in an observation record. In particular, read the supplement's
excluded pilots and use the final NoaCG drag record instead of the partial earlier one.
