# Two first-time users: text and box

Status: prepared, not run. No participant evidence is available in this session.
This checkpoint does not gate the engineering deployment or authorize wider tools.

Use [out-text-box.svg](../../../e2e/fixtures/out-text-box.svg), the same simple
import used by the numeric-key and Out browser checks. Use a fresh document for
each participant. Record the deployed revision, browser, viewport, display scaling
and introduction duration. Do not replace either person with an agent.

Read the same introduction to both people: "You are making a short broadcast
graphic. It has a title and a box. It should come on, hold until you take it off,
and be saved so you can use it again." Show the import door, then let them work.
Explain stopwatch and diamond once before the keyframe task and record that help.
Give no further hints unless they ask; record the exact hint and its time.

| Task | Observable finish | Target |
|---|---|---|
| Import and find Edit | Actual wizard result opens in Edit | Record discoverability time |
| Move | Title is in the requested new position | <=1 minute |
| Resize | Box is visibly larger, with title legible | <=1 minute |
| Two keys | Title has two different poses and scrubs between them | <=5 minutes after introduction |
| Exit | Set Out, choose reverse or manual, play to hold, then Out | Record time and errors |
| Save and reopen | Both poses and exit remain usable after reopening | <=1 minute for each ordinary edit |

Start each task's timer after reading its instruction; stop on the observable
finish. Record failed attempts as errors, including wrong layer/edge, unexpected
motion, missed save and recovery. Do not silently subtract assistance time.
