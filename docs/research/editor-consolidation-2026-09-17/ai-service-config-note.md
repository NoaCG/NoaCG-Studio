# Hosted helper configuration research

Planning defaults only: 20 turns/visitor/day, one concurrent turn, 6,000 input and 1,000 output
tokens/turn, four tool calls and one repair attempt. Measure quality/cost before choosing launch
values. A server-enforced total spend ceiling and owner-approved budget precede launch. No
paid call is authorized by a planning document. These numbers are not acceptance requirements.
Use existing gateway credentials/routing and approved fallback policy. Offline/manual editing
remains usable when service is absent, exhausted or unavailable. Model IDs are selected from
a current capability-tested listing when implementation begins.
