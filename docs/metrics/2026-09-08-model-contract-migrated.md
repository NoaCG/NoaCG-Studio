# Re-measured 2026-09-08, after `src/model` migrated

The eighth area to compile, and the largest hand-written contract left in the tree once `src/blocks`
had gone. It is also the first area where the byte win is **entirely on the Claude side**: the
generated contract is 946 bytes LARGER than the prose it replaced, and the row is still worth what
it cost. The rest of this file is why.

| Metric | Before this row | After |
|---|---|---|
| Contract corpus | 486,245 B / 102 files | **485,934 B / 101** |
| Hand-written bytes | 335,709 B / 94 files | **304,112 B / 92** |
| Generated bytes | 150,536 B / 8 | **181,822 B / 9** |
| `src/model/AGENTS.md` | 31,556 B | **32,502 B** |
| `src/AGENTS.md` | 11,762 B | **10,546 B** |
| Its chain (root + `src/` + this file) | 59,166 B used, 50,834 free | **58,896 B used, 51,104 free** |
| Claude, opening any file in the directory | 31,556 B, always | **0 B always; 737 B median for the module** |
| This area's compiled rules | - | **38,960 B across 38 scoped files** |
| Rules written | - | **70** - 25 invariants, 5 traps, 40 rules |

Bytes are LF, the form git stores. The "before" column is `origin/main` at `684e2bf2`, read with
`npm run metrics:contracts -- --at 2026-09-08`.

## The number that did not move, and the one that did

**For Codex, this row is a wash.** It reads `AGENTS.md` files, whole, so it now pays 32,502 bytes
where it paid 31,556 - 946 more. `src/AGENTS.md` lost 1,216 bytes on the same commit, because rules
that had been sitting at the `src/` level found a deeper owner the moment `src/model` became the
compiler's, so the CHAIN came out 270 bytes ahead. That is noise. `src/model` has no
subdirectories, so there is no multiplier to collect either: one chain loads this file.

**For Claude Code the shape of the cost changed completely.** Opening any file under `src/model`
used to load the whole 31,556-byte contract through the directory's `CLAUDE.md` - the durable store's
claim protocol while editing `slug.ts`, the video Template Definition while editing `csv.ts`. It now
loads **nothing directory-wide** and the module's own rules arrive with the file: every one of the
seventy rules names exactly one module, so there is no `src-model.md` at all. The median module
costs **737 bytes** and the worst, `videoTypes.ts`, costs 3,590 - a 43x cut on the median read and
almost 9x on the worst.

That asymmetry is the finding. `src/blocks` shrank 27% because its contract had become a changelog
for itself: a Phase 8 inventory of deleted modules, an autopsy, three retired code paths. This file
had almost none of that. It is 358 lines of dense present-tense rule about what a module IS and what
a caller may not do, written by people who kept it accurate, and re-expressing it as rules cost
roughly what it saved: the store's own overhead is about 70 bytes per rule for the id and the kind
label, which is 4.9 KB across seventy of them, and the evidence I could honestly move into records -
the localStorage quota arithmetic, the qz03 chip, the cross-tab reproduction, the numeral
measurements - came to about the same. **A well-kept contract does not shrink when you compile it.
It stops being loaded by people who do not need it, which is the actual complaint.**

## Seven claims were false

Each is quoted with the code that disagrees in
`contracts/records/model/2026-09-08-the-contract-this-replaced.md`, which also holds the whole file
verbatim. The two that would have cost somebody a day:

1. **"`graphics` order IS the layer stack, in PAINT order."** It has not been since a pool graphic
   gained a layer NUMBER the operator types. Every z-order consumer reads `graphicLayer(g)`;
   position in the array decides nothing. A session reaching for a way to restack a production
   would have found the sentence, reordered the array, and watched nothing move. The neighbouring
   claim - both display surfaces reverse the array, so `moveShowGraphic(+1)` means forward - was
   false twice over: neither surface reverses anything, and `moveShowGraphic` is dead code
   (`docs/backlog/dead-move-show-graphic-and-its-contract.md`).
2. **"every path that can retarget a typeface calls `ensureFontFace`: `templates/shared/base.ts` at
   build, ..."** `ensureFontFace` has no reference anywhere under `src/templates/`. `base.ts` emits
   the face CSS instead of registering it, which is the whole distinction the rule turns on: the
   guarantee is needed where a variable is retargeted AFTER the build.

The other five: the alias merge takes four tables and not three; `accentInk` resolves to the panel
colour in five of six families, not three of four (the same stale count was in `themeTokens.ts`'s
own comment, corrected on the way in); the occasion ceiling is gated in `src/templates/templateMeta.ts`
and not where the contract said; `mergeVideoInputs` cannot receive the `null` the contract told
providers to send, because that decision lives at the call site; and the legacy brand key IS still
written, by the sync seam's put. Two smaller drifts: a sync conflict copy strips five fields, not
three, and `src/model/wizard.ts` has 620 importing files under `src/`, not 619.

Three stale comments in the source were corrected in the same commit - `shows.ts`'s "the graphic
POOL, in layer order", `themeTokens.ts`'s "the other three panel on a near-black", and
`importTemplate.ts`'s "Make SPX-ready", which the button has not said for some time (it says "Make
it playout-ready", and there is no Motion panel either - motion lives in the Inspector).

## What a `fires:` declaration costs, which nobody had measured

Four rules were written with `fires: test:<spec>` because a spec genuinely pins them - the cross-tab
trap, the legibility canon, `productionData.ts`'s isolation, the CSV reader. The compiler treats a
rule whose named mechanism EXISTS as **carried**, and a carried rule is printed only in
`contracts/index.md`: not in the directory contract, not in `.claude/rules/`. That is the design
(§5.3: "an executable rule's sentence has one home"), and it assumes the mechanism carries the
sentence through `rules.text(id)`. None of these four specs does. So the honest declaration for a
rule a spec merely PINS is `fires: contract`, and `fires: test:` should wait for the mechanism to
print the text. All four were rewritten; `src/blocks` used `contract` for all sixty-nine of its
rules, and this is the reason to keep doing that.

## Six modules had no contract at all

`googleFonts.ts`, `googleFontsIndex.ts`, `storageHealth.ts`, `structuralIntent.ts`, `templateSet.ts`
and `templateVocabulary.ts` have no bullet in the file this row replaced, so no audit would ever have
noticed them missing - the same finding `src/blocks` reported about four of its own. A hand-written
contract goes stale in both directions and only one of them leaves a trace. They are not invented
here: a rule about a module nobody has read is worth less than the honest gap.

## Verification

`npm run build` read its own exit code, not a pipe's: 0. The migration audit
(`node scripts/contract-migrate.mjs audit --contract src/model/AGENTS.md --since origin/main --area
model`) reports every one of the contract's 173 backticked tokens surviving in the 404 the store now
carries, with no written drops. `check:contract-evidence` counted down from 141 evidence lines
across 44 contracts to 134 across 43, and the baseline was re-banked. `check:shared-instructions`
passes with no ceiling raised, and the three tightest chains in the repository each came down about
1,200 bytes as a side effect of `src/AGENTS.md` shrinking.
