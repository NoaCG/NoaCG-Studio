## Playout and Bridge

- CasparCG restarts: The output returns by itself after a server restart, even if the page was reloaded.
- Local files: Connect a CSV or Excel file in Chrome or Edge; it updates while the page is open.
- One-press Sheets: Paste a Sheet link and press Connect; clean matches link at once.
- Data warnings: An amber mark on the rundown shows which cue a failing Sheet or feed affects.
- Accurate live marker: The marker and PROGRAM monitor no longer show a press that never reached air.

## Editor and templates

- Cloud save status: The editor shows whether your saved work has reached the cloud.
- Multi-line SVG text: Text drawn as stacked lines gets a multi-line box and wraps inside its plate.
- Same-named graphics: Two graphics with one name no longer replace each other in a production.
