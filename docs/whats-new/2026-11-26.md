## Playout and Bridge

- Companion status: The Companion module reconnects by itself, and NoaCG shows whether Companion is really connected.
- No republish needed: A graphic added to a published rundown reaches the outputs without publishing again.
- Safer voting: Phones vote with a Vote button, and a rerun vote can continue the count or start anew.
- Question builder: Write vote options one row each, with a live phone preview and CSV export of votes.
- OSC cue rows: Each OSC cue row shows what it sent.

## Editor and templates

- Simpler import: SVG import offers one Graphic type list with plain names and names fields by their words.
- End credits: Credits can roll the whole artwork, with a new full roll template.
- Join card: A QR code card sits beside the house card in the Join picker.
- New templates: Event notification and vote lower third templates.
